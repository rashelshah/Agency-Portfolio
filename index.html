      — HOW IT GOES DOWN

      OUR
      PROCESS

      STEP 01

      DISCOVER

      A short call and a written brief. You get a scoped plan, the key user flows and a fixed quote before any design starts.

      STEP 02

      DESIGN

      A clickable prototype of the real product. You approve the look and the flows before we write a line of code.

      STEP 03

      BUILD

      Weekly slices of working software on a live staging link, so you review real progress, not slides.

      STEP 04

      LAUNCH

      We deploy, watch the first release and hand over the code and docs. If you want a next slice, we plan it together.
